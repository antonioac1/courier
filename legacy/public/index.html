How it works

Your agent creates an inbox, sends or receives email to it, and extracts verification data.

Create an inbox
curl -X POST https://getcourier.dev/alias — returns demo-abc123. Your inbox address: demo-abc123@mail.getcourier.dev.
Use it anywhere that sends email
Sign up for a service, trigger a password reset, or request a magic link — all sent to demo-abc123@mail.getcourier.dev.
Get the verification data
curl -s https://getcourier.dev/messages | jq '.messages[] | {subject, codes, links}'
Continue execution
Your agent has the OTP, magic link, or reset URL. Continue autonomously.
API Reference
POST /alias       Create inbox      curl -X POST /alias -d '{"purpose":"test"}'
GET  /aliases     List inboxes      curl /aliases
POST /incoming    Send email        curl -X POST /incoming -d "From: ...\nSubject: ..."
GET  /messages    Get emails        curl /messages?limit=5
GET  /health      Service status    curl /health
GET  /capabilities Full docs        curl /capabilities
Agent code example
# Python - zero dependencies
from courier import Courier

c = Courier()
inbox = c.create_inbox()           # Create inbox
email = c.wait_for_email(timeout=60) # Wait for email (polls)
otp = c.extract_otp()              # Get verification codes
link = c.extract_magic_link()      # Get magic links
                                      # Continue execution...
